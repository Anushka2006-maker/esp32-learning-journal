# Day 8: Multiple Displays - LCD + 7-Segment

## What I Learned

### New Concepts
- **Multiple I2C devices** on same pins
- **7-Segment Display** (TM1637) for large numbers
- **Different displays for different purposes**
- **Shared I2C bus** (SDA/SCL)

### Key Insight
I2C allows multiple devices to share the same 2 pins. Each device has its own unique address.
